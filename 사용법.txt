건축 다이어그램 에이전트 - 사용법

[다른 컴퓨터에서 받기 (git)]  저장소: https://github.com/chojoon2003-droid/diagram-maker (비공개)
처음 한 번:
 1. 명령 프롬프트(cmd) 열기 (시작 메뉴에서 cmd 검색)
 2. 저장할 위치로 이동:  cd %USERPROFILE%\Documents
 3. 받기:  git clone https://github.com/chojoon2003-droid/diagram-maker.git
 4. 처음엔 GitHub 로그인 창이 떠요 -> "Sign in with your browser" -> 본인 GitHub 계정으로 로그인
    (로그인 정보가 저장돼서 다음부터는 안 물어봐요)
 5. 문서\diagram-maker 폴더가 생겨요 -> 아래 [처음 한 번만] 진행
업데이트 받기 (코드가 바뀌었을 때):
 1. cd %USERPROFILE%\Documents\diagram-maker
 2. git pull
 - API 키 파일, outputs 등 결과물은 git이 관리하지 않아서 업데이트해도 그대로 남아요.
 - 폴더 안의 코드 파일을 직접 고쳤다면 git pull이 멈출 수 있어요.
git 없이 받기: 저장소 페이지 -> 초록색 Code 버튼 -> Download ZIP -> 압축 풀기
새 컴퓨터에서는 API 키를 앱 사이드바에 다시 넣고 저장하세요 (키는 저장소에 올라가지 않아요).

[처음 한 번만]
1. 파이썬 설치: https://www.python.org/downloads/
   설치 첫 화면에서 "Add python.exe to PATH" 체크 후 Install Now
2. 이 폴더를 원하는 곳(예: 문서)에 두고 make_desktop_shortcut.bat 더블클릭
   -> 바탕화면에 "Diagram Agent" 아이콘 생성
3. 브라우저에서 chatgpt.com 에 미리 로그인해 두기

[매번]
- 바탕화면 "Diagram Agent" 더블클릭 -> 잠시 후 브라우저에 앱이 열림
- 종료: 작업표시줄에 최소화된 검은 창을 닫기

[ChatGPT 구독 모드 사용 순서]  (API 키 필요 없음)
1. 레퍼런스: 이미지 넣기 / 원하는 느낌 쓰기 / 추천 키워드 클릭
2. 스케치: 클립보드 / 폴더 / 파일 중 하나로 불러오기
3. "🚀 ChatGPT로 보내기" 클릭
   -> 크롬에서 ChatGPT가 열리고 입력창에 프롬프트가 미리 채워짐, 이미지는 클립보드에 복사됨
4. ChatGPT 입력창 클릭 -> Ctrl+V (이미지 첨부) -> Enter
   (프롬프트가 안 채워졌으면 앱의 "📝 프롬프트 복사" -> Ctrl+V -> "🖼️ 이미지 다시 복사" -> Ctrl+V)
   (이미지가 안 붙으면 사이드바 '이미지 첨부 방식'을 '한 장으로 합치기'로)
5. 수정은 ChatGPT에 말로 요청
6. 마음에 드는 결과: ChatGPT 이미지 우클릭 > 이미지 복사 > 앱에서 "결과 가져오기"
7. 가져온 버전들은 복사(포토샵/PPT에 Ctrl+V), PNG, PPT로 내보내기 가능
   (outputs 폴더에도 자동 저장)

[📐 내 설계 자료 — 의도와 다른 내용 막기]
① 아래 '내 설계 자료 (선택)'을 펼쳐서 넣어요:
 - 설계 도면·다이어그램 이미지 (평면·단면·배치도, 기존 다이어그램 등, 최대 6장)
 - 프로그램·설계 논리 글: 직접 쓰기 / 붙여넣기 / 파일(.txt .md .pdf .docx)에서 글자 뽑기
 - '🔒 설계 자료와 스케치에 없는 내용은 추가하지 않기 (엄격)' (기본 켜짐)
역할 구분: 레퍼런스 = 스타일(어떻게 보일지) / 설계 자료 = 내용의 기준(무엇이 맞는지)
 - AI에게: 자료에 없는 프로그램·라벨·숫자·설계 행위를 지어내지 말라고 지시
 - Claude 검토: 자료의 사실(프로그램명·층수·면적·라벨)을 프롬프트에 반영
 - Claude 검수: 결과에 자료와 어긋나거나 지어낸 내용이 있으면 '수정 필요'로 잡아냄
 - 스캔한 PDF는 글자가 없어서 못 읽어요 -> 이미지로 넣어주세요
 - CAD·스케치업 파일 (.dxf / .skp):
   DXF: AutoCAD에서 '다른 이름으로 저장 -> DXF' 후 올리면 도면을 이미지로 그리고,
        도면 속 글자(실명·면적·층 표기)를 설계 글 칸에 자동으로 넣어요. (DWG는 DXF로 저장해서)
   SKP(시험 기능): 형상(3D)은 못 읽고, 파일 속 미리보기 이미지와 이름(컴포넌트·태그·장면 등)만 뽑아요.
        정확한 형태가 필요하면 스케치업에서 장면을 PNG로 내보내 넣어주세요.

[🗂️ 작업 종류: 다이어그램 / 평면 리터칭 / 단면 리터칭]  (화면 맨 위에서 선택)
- 종류마다 ① 유형(리터칭 초점), 추천 키워드, 프롬프트, Claude 검수 기준이 바뀌어요.
- 평면·단면: 정사영 유지(투시 금지), 벽·두께·개구부·계단·레벨·실명·면적을 바꾸지 말고 표현만 입히도록 지시
- 검수: 원본 도면과 비교해 벽·개구부·레벨·실명이 바뀌거나 사라지면 '수정 필요'

[🧱 형태 변형 단계]  (사이드바, 5단계 — 작업 종류마다 따로 기억)
 ① 완전 고정  : 선·벽·매스·위치·비율·시점·글자 그대로, 색·질감·그림자·첨경만 (평면·단면 기본값)
 ② 선 정리    : 삐뚤어진 선만 펴고 끊긴 선 잇기, 선 굵기 통일 (다이어그램 기본값)
 ③ 비율 다듬기 : 어색하게 틀어진 비율·정렬만 살짝 보정
 ④ 구성 정리  : 작은 디테일 단순화·병합, 간격·구도 정리
 ⑤ 재해석    : 개념·배치·부분 개수만 유지하고 형태는 자유롭게

[📐 원본 선 고정 합성]  (사이드바, 평면·단면은 기본 켜짐)
- AI 결과 위에 원본 도면/스케치의 선을 다시 겹쳐서, AI가 선을 틀어도 최종본의 선은 원본과 같게 해요.
- 결과 목록에 'AI 원본'과 '원본 선 고정'이 둘 다 추가돼요 (검수는 선 고정본에).
- 위치는 자동 정렬(특징점 매칭)로 맞춰요. 어긋나면 '선 진하기'를 낮추거나 끄세요.
- '선 인식 감도': 높이면 옅은 선·해치까지, 회색 바탕이 덮이면 낮추기
- 결과 카드의 '📐 원본 선 덮기'로 아무 버전에나 나중에 적용 가능
- 한계: AI가 선 밖에 엉뚱하게 그린 것(가구·선)은 못 지워요 -> 검수와 다시 생성으로

[📐 DXF 도면 정리]  (③ 탭 'DXF 도면')
- DXF를 올리면 레이어 목록과 추천 역할이 나와요:
  벽·구조(굵게+검정 채움) / 창호·문(가늘게) / 가구·설비(회색) / 기본 / 숨기기(치수·도곽 등)
- 역할을 바꾸고 '정리된 도면을 사용' -> AI 없이 정확하게 정리된 바탕 도면이 ③에 들어가요
- 벽 채움(포셰)은 벽 레이어의 '닫힌 폴리라인'을 채워요

[화면 구성]
① 어떤 다이어그램인지 (유형 선택 + 설명) - 가장 우선으로 반영
② 분위기·레퍼런스: 느낌을 문장으로 쓰면 구절마다 대체 단어 추천
   -> 단어 클릭 -> "선택한 단어로 문장 바꾸기"
③ 스케치 + 생성 / ④ 결과
사이드바 "화질": 초안(빠름) / 표준 / 고화질

[Gemini 실시간 추천 (선택, 무료)]
- https://aistudio.google.com/apikey 에서 구글 계정으로 키 발급
- 사이드바 "Gemini API Key"에 넣고 "Gemini 키 저장"
- 키가 없으면 내장 사전으로 추천 (그래도 동작함)
- 무료 등급은 입력 내용이 구글 서비스 개선에 쓰일 수 있음

[Codex 자동 모드]  (ChatGPT 구독으로 GPT-6 Astra 사용, 앱 안에서 자동 생성)
처음 한 번만:
 1. Node.js 설치: https://nodejs.org  (LTS 버전)
 2. 명령 프롬프트(cmd)에서:  npm install -g @openai/codex
 3. 로그인: 폴더의 codex_login_chrome.bat 더블클릭 -> 크롬에서 ChatGPT 계정으로 로그인
    (또는 앱 사이드바의 '🔑 Codex 로그인 (Chrome으로 열기)' 버튼)
 4. 앱 다시 실행 -> 사이드바 '생성 방식'에서 'Codex 자동 (구독)' 선택
사용: 스케치/레퍼런스 넣기 -> (선택) Claude 검토 -> '⚡ Codex로 자동 생성'
수정: 결과 아래 채팅칸에 수정 요청 입력 -> 같은 대화를 이어서 새 버전 생성
사용량은 ChatGPT 요금제의 Codex 한도에서 차감돼요.

[🤖 원클릭 전체 자동]  (Codex 자동 모드에서)
프롬프트 작성 -> Claude 검토 -> Codex(GPT-6 Astra) 이미지 생성 -> 결과 등록까지 버튼 한 번에.
처음 한 번만 (Codex 준비에 더해):
 1. Claude Code 설치: https://claude.com/claude-code 안내대로
 2. 로그인: 폴더의 claude_login_chrome.bat 더블클릭 -> 크롬에서 Claude 구독 계정으로 로그인
    (또는 앱 사이드바의 '🔑 Claude Code 로그인 (Chrome으로 열기)' 버튼)
사용: 사이드바 '원클릭 검토 엔진' = Claude Code (구독) -> '🤖 원클릭 전체 자동 실행'
Claude Code가 없으면 'Claude API'(키 필요) 또는 '검토 없이'로도 실행돼요.
검토가 실패하면 초안 프롬프트로 이어서 생성해요.

[🔎 결과 자동 검수 + 다시 생성]
- 사이드바 '🔎 이미지 생성 후 자동 Claude 검수'가 켜져 있으면(기본), 이미지가 나올 때마다
  Claude가 스케치·레퍼런스·다이어그램 설명과 비교해 검수해요.
- ✅ 통과: 그대로 사용
- ⚠️ 수정 필요: 문제 목록 + 수정 프롬프트(직접 고칠 수 있음)가 나와요
  -> '🔁 이 수정안으로 다시 생성 (원클릭)' : 그 이미지 + 수정 프롬프트로 다시 생성 (Codex/API 모드)
  -> '📝 수정 프롬프트 복사' / '🖼️ 이 이미지 복사' : ChatGPT 등에 직접 붙여넣을 때
- 새로 만든 이미지는 기존 이미지를 대체하지 않고 아래에 v2, v3... 로 추가되고, 자동으로 다시 검수돼요.
- 검수 엔진: Claude Code(구독) 로그인 또는 Claude API 키 중 있는 것을 사용

[🔔 완료 알림]
- 사이드바 '🔔 완료 알림'이 켜져 있으면(기본) 이미지 완성 + Claude 검수가 끝날 때
  화면 오른쪽 아래에 윈도우 알림(소리 + 결과 미리보기)이 떠요. 생성이 실패해도 알려줘요.
- 알림이 안 보이면: 윈도우 설정 -> 시스템 -> 알림 -> 알림 켜기, '방해 금지'가 꺼져 있는지 확인
